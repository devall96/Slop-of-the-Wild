# Slop of the Wild is retired

**Please use [Savage Wind](https://github.com/Revivedx/SavageWindRecomp) instead.** Slop of the Wild was built on it.

Slop of the Wild was my own build of Savage Wind with some extras. Savage Wind has since added most of them itself, and I'm sending the rest to it as pull requests instead of keeping a second version going. This page only stays up so the old in-game **Check for updates** button and old links still lead somewhere. The code is no longer here.

**Coming from Slop of the Wild?** Your saves and game files carry over. See [how to switch](https://github.com/devall96/Slop-of-the-Wild/releases/tag/0.4.2).

Thanks to everyone who tried it, and to [Savage Wind](https://github.com/Revivedx/SavageWindRecomp) and its contributors.
